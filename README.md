# Interview AI

- Built an AI-driven interview preparation platform using Next.js, React, and TypeScript, allowing users to practice mock interviews and receive automated, structured feedback.
- Integrated AI and voice technologies such as Google Gemini and Vapi for real-time, voice-based interview simulations and question generation.
- Implemented secure user authentication and data storage using Firebase.
